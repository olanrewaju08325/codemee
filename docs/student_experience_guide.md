# CodeMe Academy Student Experience Guide

## Goal
Provide a frictionless, engaging, and deeply structured journey from day one to graduation.

## The First 5 Minutes
When a student logs in for the first time, they are greeted by the `OnboardingFlow`. This wizard explains:
1. **The Structured Learning Path:** No skipping ahead. Build solid foundations.
2. **AI Co-Pilot:** The AI Tutor reads current lessons for hyper-relevant help.
3. **Daily Milestones:** Streaks and consistency.

## The Dashboard (Home Base)
The Dashboard is heavily contextual. It replaces generic course lists with a giant "Continue Learning" widget that drops the student exactly where they left off.

## Continuous Improvements
Future enhancements (Volumes) will bolt directly onto these foundational hooks (XP, Streaks, dynamic recommendations).
