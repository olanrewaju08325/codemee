# CodeMe Academy Teacher Content Guide

## Role Boundaries
As a Teacher, you only have access to courses explicitly assigned to your `user_id`.

### Capabilities:
- Create and arrange modules and lessons.
- Upload resources (PDFs, PPTXs, Source Code zips).
- Embed videos.
- Formulate quizzes and grade assignment rubrics.

### Restrictions:
- You cannot alter course pricing or enrollment windows.
- You cannot delete courses; you may only request an Archive status from an Administrator.
