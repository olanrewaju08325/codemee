# CodeMe Academy Teacher Lesson Authoring Guide

## Overview
Lessons are the atomic units of instruction. The rich-text editor supports markdown.

## AI Assistant Integration
Teachers have access to an `AIAssistantWidget`.
- Context from the editor is sent to Groq.
- The AI can draft outlines, suggest quizzes, and refine learning objectives.
- **Mandatory Review:** AI output is injected into the editor window, NOT the database. The teacher must manually review and hit Save.
