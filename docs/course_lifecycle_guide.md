# CodeMe Academy Course Lifecycle Guide

The fundamental lifecycle enforces an orderly transition from conception to retirement.

## States
- `draft`: Authors are building the skeletal structure.
- `under_review`: Content is submitted for QA.
- `approved`: Content passes QA, awaiting public launch.
- `published`: Currently live and accepting traffic.
- `active`: In-session batches are proceeding through it.
- `maintenance`: Temporarily hidden to allow for bulk safe edits.
- `archived`: Read-only. Quizzes are locked. Submissions are locked. Progress is preserved.
